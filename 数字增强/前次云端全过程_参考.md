## 2. 相较原始 ZIP 的原始源码改动：逐个文件

### 2.1 `layout_core.tex`：跨页脚注颜色继承修复

原始 ZIP 内部准确位置（注意原包有两层相同命名目录）：

`Aeneis_Full_Project_Claude_Updated_20261004/Aeneis_Full_Project_Claude_Updated_20261004/拼合工程_工作稿/制版源文件/layout_core.tex`

具体宏变更：原 `\renewcommand{\footnoterule}{\kern-3pt\begingroup\color{rulegray}\hrule width 24mm height 0.35pt\endgroup\kern 6pt}`，改为在 `\kern 6pt` 后加入 `\color{footgray}`，并补上两行原因注释。没有修改既有 `\interfootnotelinepenalty=10000`（每条脚注不跨页断开）、字号、行距、正文版式或被引用文字。

**原因与证据：** 在初编版中，534 条脚注里有 22 条被整条推往后页；这些注释被渲染成纯黑，而其余 512 条使用规范灰蓝色 `#596166`。原脚注内部虽设灰色，插入盒经输出例程延期时颜色状态没有在正确时点生效。修复后对 534 个注号及脚注区域 2,970 个文本片段做 PDF 实物色值检查，均为 `#596166`。

**可迁移性：** 这是一条具体的 XeLaTeX 输出例程修复；若日后调整脚注插入／色彩宏包组合或页码，必须重新运行全书颜色审计，不能只看 TeX 定义。

### 2.2 `claude_colophon.html`：版本记微调与填实字体说明

原始 ZIP 内部准确位置：

`Aeneis_Full_Project_Claude_Updated_20261004/Aeneis_Full_Project_Claude_Updated_20261004/末页设计/claude_colophon.html`

### 3.2 `build_pdf_accessible.py` 的主要逻辑（勿重新造轮子）

1. **534 条脚注定位**：通过 PyMuPDF 遍历现有命名目标 `Hfootnote.1` 至 `Hfootnote.534`，从脚注实际落页取对应打印注号坐标，逐条确认唯一匹配。跨页脚注同样被匹配。
2. **双向点击**：保留正文上标 → 脚注目标（534 条），略微扩张点击矩形；另外给脚注开头编号生成独立的 `/Link` 注释，目标为原文对应上标位置（534 条），无可见回箭头和链接边框。
3. **术语链接**：根据固定的 30 个精选专名，扫描各卷正文首次出现，并定位附录实际词条行；最后生成 173 条正文 → 术语表链接。不是对 115 个词条逐一建全部回链；不支持“动态返回原来那一次引用处”的通用 PDF 操作。
4. **Tagged PDF**：创建 `/StructTreeRoot`、`/ParentTree`、页面 `/StructParents`、内容 MCID、`/Document /Sect /H1 /P /Note /Figure /Link`，按每条编号脚注生成独立 `/Note`（总 534）。1,275 个链接注释通过 `/StructParent` / `/OBJR` 关联；脚注注号 MCID 与相应 `/Link` 层级挂接。**这是语义标记的具体实现，不是 PDF/UA 合规证明。**
5. **图片说明**：17 个图形语义对象（封面 1、十二幅卷首版画、地图 3、版本记 1）设置 `/Alt`；非重要重复绘制对象以 Artifact 处理。地图复杂内容的文字等价性仍需人工评估。
6. **字体**：将导入地图资源里唯一未嵌入的 Helvetica 字体定义映射到系统安装的 Liberation Sans Regular，保留原 Helvetica 宽度数据以减少坐标变化；给 WinAnsi 编码建立 `/ToUnicode` 映射。最终 `pdffonts` 显示无未嵌入项。但此做法不是逐字字形兼容的国际标准认证，后续应在不同渲染器和文本复制环境复核。
7. **导航和元数据**：保留原 43 项目录基础，扩充图版地图索引、每卷／约每 100 原诗行书签，共计 168 项；补充中文标题作者、主题、XMP、文档语言和阅读器显示标题偏好，保留末页 2 条 URI 外链。

**易碎点 / 移植风险：** 脚本并非完全从权威 TeX 语法树生成，部分结构依靠页面坐标、字号、颜色和 PDF 绘图顺序推断；第 8、33、59、83、107、134、165、192、216、243、272、301 页等卷次边界被写死；术语表约在 PDF 索引 331—336；图版索引和字体位置均是本次定稿版的特定常量。**只要更换版式、译注、地图或 LaTeX 版本导致分页/字体改变，就必须重新验证乃至重写这些定位逻辑，不可盲目套用。**

## 7. 下一位接手者应当怎么做（省时顺序）

1. **锁定原包 + 终版 SHA**，先确认确实拿到 `8c05...` 原始 ZIP 与 `2f8d...` 交付 PDF，避免混用中间版本；留存原物不覆写。
2. **阅读 `源码哈希与补丁信息.json`、两个 patch 和 `脚本_最终版`**，再动项目；不要直接基于旧 `aeneis_accessible_build.py` 继续改。
3. 若只是检查当前 PDF，**不要重编译**，优先运行 `audit_pdf_release.py`、pdfinfo/pdffonts 和人工阅读器测试；只有出现确定缺陷才另建版本。
4. 若需要进一步修复语义结构，最好从 LaTeX 源头确定卷、诗行、注号和术语的 ID/关系，而不是继续增加依赖页码、字号阈值的 PDF 坐标启发式；否则后续一改分页就容易失效。
5. 任何重新编译都要再次检查跨页脚注颜色、534 个正向＋534 个反向目标、173 个术语链接、17 个 Alt、168 书签、字体 Unicode、338 页文字和已批准的末页对齐。**不能靠 338 页数字相同就宣布全部合格。**
6. 对 PDF/UA 与全文无障碍实测做独立报告，在报告通过之前只可表述为“含 Tagged PDF 内容标签／未认证”。
